# Sol System - Planet Textures

Place textures for planets here:

## Earth
- `Earth_color.png` (8K recommended)
- `Earth_normal.png`
- `Earth_specular.png` (ocean reflections)
- `Earth_clouds.png` (with alpha transparency)
- `Earth_night.png` (city lights)

## Mars
- `Mars_color.png` (4K recommended)
- `Mars_normal.png`

## Venus
- `Venus_color.png`
- `Venus_clouds.png`

## Gas Giants
- `Jupiter_color.png` (8K recommended)
- `Saturn_color.png`
- `Uranus_color.png`
- `Neptune_color.png`

## Others
- `Mercury_color.png`

All textures should be in equirectangular projection (2:1 aspect ratio).
