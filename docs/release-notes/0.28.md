# Kosmos 0.28

## Tools
- planetbake, a new program in `addons/planetbake/bin` next to KosmosMap (also in the SDK, with its source), bakes a generated world into colour, height, normal, specular and night-lights maps as PNG or DDS (BC1, BC3 or uncompressed, with mip chains), as single images up to 16384 wide or as resumable tile pyramids up to 65536 wide. It has a GTK 3 window with a 1024x512 preview and a button for each layer, and a command line. It uses the game's own generator, so the maps match the game, and never more than 4 threads. The SDK download carries its source and Linux and Windows programs.
- `--gen-world` and `--bake-planet` print the planetbake command line that makes the same world.
- `--gen-world NAME` (with `--system`) makes one world's far-view image into the cache from the command line, up to 16384 wide, on at most 4 threads and 4 GB (`--gen-width`, `--gen-threads`, `--gen-memory`). Settings > World texture 16384 still makes every world in a system.
- KosmosMap's scan is capped at 4 threads, and the build and media scripts (make-gallery, make-promo, the build and release scripts) never use more than 4.

## Documentation
