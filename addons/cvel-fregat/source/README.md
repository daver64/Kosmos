# Fregat model source

The included `fregat.msh` is the source of `../models/fregat.obj` and
`../models/fregat.mtl`. Both files match a fresh conversion using
`tools/msh_import.py`, which converts the coordinate system. The model
does not use external textures.

The included `CVEL-Fregat.txt` credits D Henderson and states that the
module, source code and meshes are released under the GNU LGPL without
specifying a version. The LGPL 2.1 text is included for reference; its
inclusion does not claim that the upstream notice specified that version.
