# Kosmos 0.49

- The Keyboard window groups all bindings under one header per category, avoiding ImGui ID conflicts when sections are collapsed.
- Fixed triangular artifacts on the Ariane 5 fairings.
- Ariane 5's two boosters now separate outward independently rather than falling away as one rigid pair.
- Soyuz solar arrays now generate power only when deployed; solar generation also reflects the current star's luminosity.
