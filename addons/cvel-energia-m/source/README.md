# CVEL Energia-M source and attribution

The original `Energia-M.txt` credits Erik Anderson (Sputnik) for the Energia-M
meshes and Dave Rowbotham for booster and logic integration. The CVEL author
confirms that Erik's CVEL fleet meshes are covered by the fleet licence and
may be included. The notice explicitly identifies the C++ module code as
LGPL; it does not separately spell out the mesh licence.

Kosmos converted the five launcher meshes from the CVEL Energia-M distribution
to OBJ/MTL, reflected the Z axis, converted referenced DDS textures to PNG,
and removed coincident faces. The original source meshes and notice are
included here. Use `tools/import_cvel_energia_m.py` to reproduce the conversion.
