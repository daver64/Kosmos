# Kosmos 0.63

## Changes

- Added the optional **Kosmos high-resolution maps** scenery pack to the launcher. It contains original Celestia Earth colour and normal tiles and is for non-commercial use only; the bundled source notices give attribution and terms. Orbiter scenery remains available separately.
- Added the CVEL Atlas IIAS and Atlantis launch scenarios at Kennedy and Ariane 44L at Kourou. Atlantis uses a separate launch-stack vessel: undock and switch to the shuttle after main-engine cutoff, then use OMS to reach orbit. Guidance and staging are approximate.
- Added the CVEL Vulcan aircraft and a Wagga Wagga scenario carrying a Deltaglider.
- ShipEdit can create and edit scenarios, add docked piggyback vessels and edit docking ports. Docked vessels remain separate ships, so the piggyback ship's engines do not contribute to the carrier's thrust.
- ShipEdit links overlapping powered stages for simultaneous ignition and arranges marked radial boosters before their core. Review staging flags and positions, especially after repacking; performance estimates still assume sequential burns.
- ShipEdit and KosmosMission can request Vulkan with `--vulkan` or OpenGL with `--gl`. OpenGL remains the default; if Vulkan is unavailable, the tools warn and fall back.
- Corrected propulsion values and exhaust appearance for several CVEL launchers, and improved Ariane fairing lighting and exhaust.
