# Kosmos 0.54

## Install and run

- **Windows (64-bit):** Download `kosmos-beta-0.54-Windows.zip`, right-click it in File Explorer and choose **Extract All**. Open the extracted folder and run `kosmos-launcher.exe` there, not from inside the ZIP. Use Windows 10 or later, current graphics drivers and the Vulkan runtime (`vulkan-1.dll`).
- **Linux (64-bit):** Download `kosmos-beta-0.54-Linux.tar.gz`, extract it, and run `./kosmos-launcher` from the extracted folder. The build requires glibc 2.38 or newer, a graphical desktop and OpenGL 4.3 drivers.

On Ubuntu 24.04, install the Linux runtime libraries with:

```sh
sudo apt install libwxgtk3.2-1t64 libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-mixer-2.0-0 libsdl2-ttf-2.0-0 libcurl4t64 libpng16-16t64 libopengl0 libvulkan1 zlib1g
```

The included fallback scenery is enough to get started. The larger Orbiter scenery downloads and the SDK are optional. The launcher's Update downloads the complete distribution into a new sibling folder; it does not update the existing folder or move scenery installed there.

## Changes

- Grouped the launcher's Addons page into expandable folders, including CVEL and KosmosLink Apps. Select an addon to see its details and enable or disable it; addon authors can set a launcher category in their manifest.
- Orbiter terrain now uses the scenery installed in the current Kosmos folder by the launcher, including the optional standard packs. Legacy high-resolution source folders and separately selected Orbiter installations are no longer scanned; install the scenery again through **Scenery packs** if needed.
- Fixed Saturn V-23L liftoff: the core engines now burn alongside the liquid boosters, and continue after the boosters separate. Both the standard and payload variants are affected.
