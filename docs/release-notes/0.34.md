# Kosmos 0.34

- Map MFD redesigned: surface map of the current body, predicted ground track, impact point and time, orbit numbers, and an optional target base.
- Deltaglider and Shuttle-A panels now work: fuel gauges, engine needles with thrust and acceleration numbers, RCS mode switches and fuel bars.
- New panel control types `needle`, `bar` and `number`, `knob` and `lever` button styles, and `rcs_propellant` / `rcs_isp` ship fields.
- Virtual 3D cockpits for the Deltaglider and Shuttle-A (`cockpit.vc_model`), with live MFD screens. `tools/msh_import.py` splits `*DISPLAY` mesh groups into their own materials.
- Deltaglider VC: hi-res Orbiter textures, a working HUD on the HUD plate (`--hud surface` for aircraft), mouse-pickable MFD screens, and throttle, hover, gear, nose-cone and airbrake levers that move (`cockpit.vc_animations`). Left and right MFDs are no longer swapped.
- The Transfer MFD's "next window" countdown now counts down.
- Time warp up to 100x is allowed while sitting stationary on the ground, so launch-pad scenarios no longer crawl.
- Deltaglider VC: MFD bezel buttons (columns, SEL/MNU row), HUD mode buttons, the nav-mode buttons, and the gear, nose-cone, airbrake and undock levers, RCS dial and light switches can be clicked (`cockpit.vc_hotspots`); the overlapping propellant-status variants no longer z-fight (`cockpit.vc_hide`).
- New "MFD / HUD filtering" setting (Bilinear, Supersampled 2x or 4x, default 2x): the VC MFD and HUD textures are drawn larger and averaged down, which keeps small text crisp.
- New Anti-aliasing setting (Off/2x/4x/8x, default 4x) in Settings. Model textures were already mipmapped with 16x anisotropic filtering.
- VC hotspots can follow an animated part (`follow`), so clicking the gear, nose-cone and airbrake levers works wherever the lever currently sits. The hover throttle lever now moves.
- New controls `/controls/af-mode` (on/pitch/off), `/controls/trim`, `/controls/gimbal-pitch` / `gimbal-yaw` (ship field `gimbal_range`) and an airlock model (`/controls/airlock/*`, `/airlock/pressure`) in the flight model.
- Fixed VC clicks missing after changing the field of view (Z/X): picking now uses the live FOV. Levers can be clicked at rest or swung. Added held-drag hotspots (`drag`, `drag_gain`) for the Deltaglider main and hover throttle levers.
- `--set /sim/settings/vc-hotspots=1` outlines every VC hotspot and logs each click's ray, for ship authors.
- Deltaglider VC levers now start in Orbiter's rest pose (animation `initial` is the state at which the mesh is unrotated, as in Orbiter), so the airbrake lever starts up and the gear lever down. `--cam-yaw`/`--cam-pitch` also turn the head in the 3D cockpit.
- Deltaglider: working AF CTRL dial (all axes / pitch only / off), elevator trim, main-engine gimbal and an airlock with pressure (inner and outer doors never open together, the outer only in vacuum). They are on the 2D panels and the VC (AF dial, trim wheel, gimbal and airlock switches), taken from Orbiter's mouse areas. New panel controls `nudge` and `step`.
- The VC MFD textures no longer draw their own bezel buttons (the model has them), so SEL/HLP are not doubled.
- Deltaglider VC: the artificial horizon between the MFDs is live (new cockpit field `vc_instruments`). The display below it is now a live HSI (the stock HSI MFD drawn bare, with heavier strokes) tracking the NAV 1 VOR/ILS; instrument entries can be `vc_only` so they stay off the 2D panel.

- Cockpits can list `mfd_hide` mode ids to suppress. The Deltaglider no longer offers the airliner six-pack MFDs.
- Deltaglider: the DG Slope instrument shows the whole descent-slope unit instead of a magnified crop; a stray SCRAM temperature quad that floated in front of the pilot's eye is hidden.
- Cockpit tooltips: hovering a control in the 2D panel or the 3D cockpit shows its name (new Settings option "Cockpit tooltips"; hotspots and panel controls take an optional `label`).
- Deltaglider VC: the HUD-mode and nav-mode button labels now show their text (label strips are alpha-blended) and the artificial horizon is no longer upside down.
- Deltaglider: the AOA and Slip instruments are no longer offered as selectable MFD modes (they stay on the 2D panel). `cockpit.mfd_hide` now only stops a mode being chosen; a panel can still place a hidden mode on a fixed instrument.
- Four more minor bodies from Orbiter's Celbody data: Nereid (Neptune), Himalia (Jupiter), Hydra and Nix (Pluto), with Orbiter's Hydra and Nix textures. `tools/celbody_import.py` adds them to `data/sol.json`.
- Shuttle-A VC: the 3D cockpit is now usable. Clickable MFD buttons, nav-mode buttons, pod-angle presets and up/down switch, RCS-mode switch and landing-gear switch, draggable main, hover and pod throttle levers that slide with the throttle, tooltips on all of them, the eye moved to Orbiter's camera position, and the six-pack MFD modes hidden. `vc_animations` entries can now slide a part with `move` instead of rotating it, and a `nudge` of `/controls/pod-tilt` moves both pods.
- Shuttle-A VC: the engine and pod-angle gauges between the MFDs now work (`vc_gauges` redraws the part's texture with live needles), switches and levers are shaded so they look 3D, the nav-mode and pod-angle buttons show the selected one with a red outline (`outline_active`), and the hull-shell walls no longer show stretched exterior textures.
