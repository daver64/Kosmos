PROTON / KOSMOS PBR - FIRST PASS

Five original OBJ meshes are unchanged. MTL files are updated for simlib PBR:
Pm metallic factor; Pr roughness factor; map_Kd albedo; map_Bump tangent-space normal.
Procedural texture maps are generated for each material using the existing UVs.
All texture paths are relative to the OBJ files.

IMPORTANT: The original image textures (protnozzle.png, strproton.png,
protoncover.png, Proton3rd.png) were not included in the upload.
These are NEW approximate replacement surfaces, not enhancements of the originals.
Some materials have overlapping/tiled UVs, so labels and location-specific features
cannot be guaranteed without UV editing. Inspect in Kosmos and adjust as needed.
Existing MTL diffuse colours were approximated by semantic material category.
