# Kosmos 0.60

## Changes

- Corrected the ISS model's lighting and overlapping panel surfaces, including the nuclear variant.
- Switching the camera to another ship no longer plays a spurious docking or undocking sound.
- Added fixed-step PNG frame capture with optional ship-tracking camera keyframes. This offline mode does not record audio; the source tree includes a showreel workflow for assembling video and sound.
- `--sunlit` now works around planets in other star systems as well as Sol.
