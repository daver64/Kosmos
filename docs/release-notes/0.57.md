# Kosmos 0.57

## Changes

- Orbiter relief near the ground is now off by default, using the existing terrain renderer instead. It can be enabled in the launcher's Options page; when enabled, it is limited to 512 visible ground patches, independently of orbital relief. This reduces the workload in the tested Soyuz descent, though performance and appearance vary.
- Fixed OrbitComp orbit drawings extending outside the MFD when zoomed in, and preserved the external camera's direction and roll when crossing a body's sphere-of-influence boundary. Flight recordings now preserve camera roll; older recordings remain supported.
- Reduced the Soyuz TMA service module's main-engine exhaust and moved its RCS effects to approximate service-module locations. Addons can specify a stage-local RCS visual layout without changing the spacecraft's RCS physics.
- Batched exhaust particle rendering to reduce draw calls.
