## Kosmos 0.15

### Interface
- MFD and panel instruments now suit the ship: aircraft no longer offer the orbital displays, and spacecraft no longer show the airspeed, vertical speed, turn and heading gauges. The Skylark's Navigation panel now carries an HSI instead of the Orbit display.
- The COM/NAV and other nav displays show short ICAO-style idents (e.g. `EGCP VOR`, `EGCP ILS 1R`) instead of long names that overran the screen.

### For addon authors
- MFD modes in an addon manifest can set `"domain"` (`space` or `atmosphere`), and a ship's `cockpit.mfd_filter` (`auto`, `atmosphere`, `space`, `none`) controls which are offered. Use `none` for a spaceplane.
- Bases take an optional `"icao"` code (made up from the id if absent), and navaids an optional `"ident"`.
