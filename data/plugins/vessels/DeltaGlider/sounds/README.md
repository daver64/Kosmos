# DeltaGlider Sounds

Place audio files here:
- `main_engine.ogg` - Main engine thrust sound (looping)
- `hover_engine.ogg` - Hover thruster sound (looping)
- `rcs_thrust.ogg` - RCS thruster pops
- `landing_gear.wav` - Landing gear deployment
- `cockpit_ambient.ogg` - Cockpit background hum (looping)

Recommended format: OGG Vorbis for compression, WAV for short effects
