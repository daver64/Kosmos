# Kosmos 0.59

## Changes

- ShipEdit has a visual stage library: drag stages from addon ships into a rocket stack, or click to add them at the nose. Model assets and animations are copied on save; ship-wide scripts and systems are not imported. Launching the saved ship starts it on the Chippenham pad.
- New ShipEdit rockets have cockpit and external MFDs and an experimental, configurable Earth-launch gravity-turn autopilot.
- An explicit `--ship Kestrel` start no longer gets replaced by the default scenario.
- Bundled tool executables are available beside Kosmos in the build directory and release archives, as well as in their addon folders.
