# Kosmos 0.56

## Changes

- Added experimental base-targeted autoland for the complete, undocked Soyuz TMA in Earth orbit. It searches for a window without a plane change, burns retrograde, separates the modules and aims to deploy the first parachute within 100 km of the chosen base. Weather may be enabled but is ignored by the prediction; nonspherical gravity must be off. The Spacecraft autopilot window shows deorbit and estimated 120 km entry countdowns. Monitor the flight and take over if needed.
- The Soyuz TMA orbit scenario now starts at a fixed date and in a 55-degree orbit with an early window for Twickenham or Chippenham. Changing the orbit or date changes the available windows.
- Added the fictional radioisotope-powered Luna E3 RTG and use it in the probe scenarios around bodies whose heliocentric orbits lie beyond Earth's. The original solar-powered Luna E3 remains available.
- Added planet, moon and asteroid scenarios, NASA asteroid shapes and the NASA Gateway with a Shuttle-A in a fictional low lunar orbit. The Venus cloud-top image uses a higher-resolution Solar System Scope map; sunlight and glare now dim with distance.
- Fixed severe stuttering during fast atmospheric flight, Buran's gear extending after separation, and visual fighting on its bay doors. Stationary landed inactive vessels no longer prevent time warp solely because they are in an atmosphere; an airborne spent Energia core still limits warp until it lands or crashes.
- Restored Deltaglider virtual cockpit artwork and repaired Shuttle-A virtual cockpit texture mapping. The first framed MFDs now appear near the lower corners, and the Map MFD displays the current body's surface texture again, including on tiled Earth.
- Orbiter terrain microdetail is built by default with relief for fresh configurations. It needs separately installed Orbiter microtexture assets; existing build configurations that cached it off must enable it explicitly.
- Planet configurations can tune close-orbit haze with `atmosphere.close_orbit_haze`; it affects appearance, not atmospheric density or drag.
