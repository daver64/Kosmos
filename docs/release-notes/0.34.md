# Kosmos 0.34

- Map MFD redesigned: surface map of the current body, predicted ground track, impact point and time, orbit numbers, and an optional target base.
- Deltaglider and Shuttle-A panels now work: fuel gauges, engine needles with thrust and acceleration numbers, RCS mode switches and fuel bars.
- New panel control types `needle`, `bar` and `number`, `knob` and `lever` button styles, and `rcs_propellant` / `rcs_isp` ship fields.
- Virtual 3D cockpits for the Deltaglider and Shuttle-A (`cockpit.vc_model`), with live MFD screens. `tools/msh_import.py` splits `*DISPLAY` mesh groups into their own materials.
- Deltaglider VC: hi-res Orbiter textures, a working HUD on the HUD plate (`--hud surface` for aircraft), mouse-pickable MFD screens, and throttle, hover, gear, nose-cone and airbrake levers that move (`cockpit.vc_animations`). Left and right MFDs are no longer swapped.
- The Transfer MFD's "next window" countdown now counts down.
- Time warp up to 100x is allowed while sitting stationary on the ground, so launch-pad scenarios no longer crawl.
- Deltaglider VC: MFD bezel buttons (columns, SEL/MNU row), HUD mode buttons, the nav-mode buttons, and the gear, nose-cone, airbrake and undock levers, RCS dial and light switches can be clicked (`cockpit.vc_hotspots`); the overlapping propellant-status variants no longer z-fight (`cockpit.vc_hide`).
- New "MFD / HUD filtering" setting (Bilinear, Supersampled 2x or 4x, default 2x): the VC MFD and HUD textures are drawn larger and averaged down, which keeps small text crisp.
- New Anti-aliasing setting (Off/2x/4x/8x, default 4x) in Settings. Model textures were already mipmapped with 16x anisotropic filtering.
- VC hotspots can follow an animated part (`follow`), so clicking the gear, nose-cone and airbrake levers works wherever the lever currently sits. The hover throttle lever now moves.
- New controls `/controls/af-mode` (on/pitch/off), `/controls/trim`, `/controls/gimbal-pitch` / `gimbal-yaw` (ship field `gimbal_range`) and an airlock model (`/controls/airlock/*`, `/airlock/pressure`) in the flight model; panel and VC switches for them are not wired yet.
- Fixed VC clicks missing after changing the field of view (Z/X): picking now uses the live FOV. Levers can be clicked at rest or swung. Added held-drag hotspots (`drag`, `drag_gain`) for the Deltaglider main and hover throttle levers.
- `--set /sim/settings/vc-hotspots=1` outlines every VC hotspot and logs each click's ray, for ship authors.
