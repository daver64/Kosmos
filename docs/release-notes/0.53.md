# Kosmos 0.53

## Install and run

- **Windows (64-bit):** Download `kosmos-beta-0.53-Windows.zip`, right-click it in File Explorer and choose **Extract All**. Open the extracted folder and run `kosmos-launcher.exe` there, not from inside the ZIP. Use Windows 10 or later, current graphics drivers and the Vulkan runtime (`vulkan-1.dll`).
- **Linux (64-bit):** Download `kosmos-beta-0.53-Linux.tar.gz`, extract it, and run `./kosmos-launcher` from the extracted folder. The build requires glibc 2.38 or newer, a graphical desktop and OpenGL 4.3 drivers.

On Ubuntu 24.04, install the Linux runtime libraries with:

```sh
sudo apt install libwxgtk3.2-1t64 libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-mixer-2.0-0 libsdl2-ttf-2.0-0 libcurl4t64 libpng16-16t64 libopengl0 libvulkan1 zlib1g
```

The included fallback scenery is enough to get started. The larger Orbiter scenery downloads and the SDK are optional. The launcher's Update downloads the complete distribution into a new sibling folder; it does not update the existing folder or move scenery installed there.

## Changes

- Removed duplicate Titan textures whose filenames differed only in capitalisation, preventing two overwrite prompts when extracting the Windows ZIP.
- The launcher now recovers if an HTTP download cancellation does not report completion, allowing a paused download to be resumed or the launcher to close. Partial downloads remain available for resuming where the server supports it.
- Added a turnkey release workflow that builds and verifies the packages, publishes to GitHub and updates the website. It reuses unchanged scenery assets and checks the Windows ZIP for filename collisions.
