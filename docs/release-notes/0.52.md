# Kosmos 0.52

## Install and run

- **Windows (64-bit):** Download `kosmos-beta-0.52-Windows.zip`, extract it, and run `kosmos-launcher.exe`. Use Windows 10 or later, current graphics drivers and the Vulkan runtime (`vulkan-1.dll`).
- **Linux (64-bit):** Download `kosmos-beta-0.52-Linux.tar.gz`, extract it, and run `./kosmos-launcher`. The build requires glibc 2.38 or newer, a graphical desktop and OpenGL 4.3 drivers. On Ubuntu 24.04, install the runtime libraries with:

  ```sh
  sudo apt install libwxgtk3.2-1t64 libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-mixer-2.0-0 libsdl2-ttf-2.0-0 libcurl4t64 libpng16-16t64 libopengl0 libvulkan1 zlib1g
  ```

The included fallback scenery is enough to get started. The larger Orbiter scenery downloads and the SDK are optional.

## Changes

- OrbitComp labels closest approach to a body as altitude above its reference radius instead of distance from its centre; ship targets still show separation. Negative altitude indicates an intersection with the reference sphere. Predictions remain approximate and do not account for terrain or atmosphere; ORB and HEL do not include the target body's gravity.
- Fixed the Windows launcher rejecting the Orbiter high-resolution minor-body archive during installation. A previously downloaded archive can be reused by retrying the pack.
- Updated the SDK protocol documentation: HELLO accepts versions 1 to 3, and WELCOME reports the server's version.
- The launcher can use unchanged standard scenery packs from earlier GitHub releases. Upgrade the launcher to 0.52 before downloading those packs: 0.51 does not accept the version-pinned catalogue URLs. Existing installed scenery is unaffected.
