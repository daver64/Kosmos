# Kosmos 0.32

## Changes
- The download archives now carry the version in their name, for example `kosmos-beta-0.32-Windows.zip` and `kosmos-beta-0.32-Linux.tar.gz`, and unpack into a folder of the same name. The download page and the launcher's update check use the new names.
- The README, download page and developers manual now say that Kosmos is feature complete: from 0.30 on, releases are bug fixes and performance work, with no major new features.
- On Windows `kosmos.exe` is now a GUI program: it no longer opens a console window. Started from a terminal it still prints there, and the new `--console` option opens a console window for its output.
- Fixed Kosmos starting with no window (running but invisible) when started from the launcher on Windows. The launcher asked Windows to hide the new program's window.
