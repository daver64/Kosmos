# Kosmos 0.47

- KosmosMission carries payload ships: add any ship, several kinds and counts (a Dragonfly and a dozen probes), at their full mass, and it checks they fit the launcher's payload volumes. Ships declare volumes with `payload_bays` (cylinders or boxes) and their own size with `payload_size` in `ship.json`. The fit check is conservative. Without a declared volume the mass counts but nothing is checked.
- Payload stacks: build a 2-3 stage stack (for example Centaur G, Fregat, a probe) with Add to stack / Add stack. It counts as one payload, its mass and size are summed, and its own delta-v is added to the budget.
- When you save a mission or start the game, the first unit in each bay is docked to the launcher in the scenario (a stack docks bottom to top). A bay names its launcher port with `"port"`; anything that did not fit or had no free port is listed in the scenario description as not placed.
- All the CVEL launchers (Saturn V variants, Ariane 5, Atlas, Delta IV, Proton, the Titans, Buran, Energia, Energia-M, Centaur, Fregat and the Shuttle-A pods) now declare payload bays. The sizes are estimates, not measured. The Saturn V variants gained a nose Payload port to dock to.
- KosmosMission's ship list now includes the variants listed in an add-on's `addon.json` `"ships"` (Titan models, Ariane 5 ES and ECA, Energia, Soyuz, Shuttle-A pods), not only each add-on's `ship.json`.
- The launcher has a KosmosMission button on the Play page. KosmosMission can start Kosmos itself (with the mission as the scenario, via `--link`) when you press **Start Kosmos with this mission** or **To game** and no game is running; it then sends the leg once the game answers.
- The tools that ship with Kosmos (KosmosMission, KosmosMap, KosmosCAD, KosmosAV, ShipEdit) are now allowed to connect without approval. Other native addons still need allowing under View > Native addons.
- KosmosMission has a **Guide** button and a web-page walk-through of a complete mission: assemble a stack, fly the ascent, then a Lambert or Hohmann leg.
- Fixed a GTK deprecation warning (`G_APPLICATION_FLAGS_NONE`) in the Windows build of KosmosMission.
