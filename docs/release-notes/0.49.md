# Kosmos 0.49

- The Keyboard window groups all bindings under one header per category, avoiding ImGui ID conflicts when sections are collapsed.
- Fixed triangular artifacts on the Ariane 5 fairings.
- Ariane 5's two boosters now separate outward independently rather than falling away as one rigid pair.
- Soyuz solar arrays now generate power only when deployed; solar generation also reflects the current star's luminosity.
- Atlas III now drops its first stage and both fairing halves together, so one staging command reaches the Centaur. Chained `with_next` stages also let the three-piece Titan fairings separate together.
- The launcher autopilot now reads telemetry from the active ship rather than always using the first ship in the scenario.
- The HUD marks a retained autopilot status as off when the autopilot is no longer engaged.
- Kerosene rocket exhaust expands less in thin air, while keeping its ground-level appearance.
- Luna E3's cockpit view now faces the other way, and its oversized generic RCS puffs are hidden.
- Smoothed atmospheric hydrogen exhaust and retuned Delta IV Heavy's booster plumes to avoid separated blue blobs at liftoff.
- Removed the bundled Argo, Piper Cub and Vulcan scenarios because their ship addons are no longer included.
- Reduced the Transtage exhaust effect; Titan III-C and 34D now have two correctly positioned Transtage thrusters with unchanged combined thrust.
- Missing scenarios or scenario ships now report an error instead of silently launching a different or incomplete flight; the launcher refreshes a removed scenario selection.
- Added experimental untargeted Mars autoland for compatible nose-axis hover landers such as the Ares Spider: deorbit, atmospheric coast and powered descent.
- Grouped the Ares Spider Gale Crater scenario with a new 200 km Mars orbit scenario under CVEL-Ares.
- Clarified orbital speed versus surface speed, added a RADALT MFD with estimated local terrain clearance and stabilized heading near vertical.
- Added hover throttle controls and timed spacecraft burns with countdown or UTC ignition, SAS attitude, duration and throttle.
- Ares Spider's deployed landing legs now splay outward, with touchdown contacts aligned to the feet; the existing stowed pose is unchanged.
- Added experimental Ares, Deltaglider and Shuttle-A ascent MFDs with separate Mars or Earth flight profiles and orbital circularisation.
- Fixed prograde and retrograde SAS and burn-alignment checks using rotating-surface velocity instead of orbital velocity, especially noticeable in high planetary orbits.
- Fixed generic linear RCS applying full thrust even for small control inputs.
- Fixed cockpit input using stale GUI mouse capture and released the EVA mouse pointer for all registered tool and autopilot windows.
- Kept ImGui button releases and focus changes synchronized during loading and hyperspace transitions to prevent stuck input afterwards.
