# Kosmos 0.45

- File ▸ Set time to T-5:00 before burn keeps re-planning for more passes, so long waits (Mars, Jupiter) end at the lead time instead of well short of it.
- The lead time for Set time to before burn is never less than five minutes. A lead of 0 skipped right onto the ignition, and the plan could then slip past it to the next window (days later).
- OrbitComp PLN warns in red when the active stage does not have the dV the plan needs ("NOT ENOUGH dV"), and AUTO will not arm for it. An outer-planet transfer such as Uranus needs several km/s more than a Deltaglider carries, so the burn ran dry and the ship fell far short.
- OrbitComp ORB and MAN keep your ship's dot on the display: the plot scales to include the ship (an escape or heliocentric path used to push it off the screen), and any marker still out of range is pinned to the edge of the plot.
