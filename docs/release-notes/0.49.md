# Kosmos 0.49

- The Keyboard window groups all bindings under one header per category, avoiding ImGui ID conflicts when sections are collapsed.
- Fixed triangular artifacts on the Ariane 5 fairings.
- Ariane 5's two boosters now separate outward independently rather than falling away as one rigid pair.
- Soyuz solar arrays now generate power only when deployed; solar generation also reflects the current star's luminosity.
- Atlas III now drops its first stage and both fairing halves together, so one staging command reaches the Centaur. Chained `with_next` stages also let the three-piece Titan fairings separate together.
- The launcher autopilot now reads telemetry from the active ship rather than always using the first ship in the scenario.
- The HUD marks a retained autopilot status as off when the autopilot is no longer engaged.
- Kerosene rocket exhaust expands less in thin air, while keeping its ground-level appearance.
- Luna E3's cockpit view now faces the other way, and its oversized generic RCS puffs are hidden.
- Smoothed atmospheric hydrogen exhaust and retuned Delta IV Heavy's booster plumes to avoid separated blue blobs at liftoff.
- Removed the bundled Ares Spider, Argo, Piper Cub and Vulcan scenarios because their ship addons are no longer included.
