# Kosmos 0.61

## Changes

- Improved the CVEL Titan launchers: added normal maps for more detailed PBR lighting, corrected fairings and interstages, fixed booster/core staging and pad reload behavior, and made Orbit and Surface MFDs available. The Centaur-equipped variants now use both engines.
- Reworked Delta IV Heavy exhaust placement and plume size; tuned the Titan 34D and IIIC core and second-stage plumes.
- Slowed the lowest cloud layer near the ground.
- Improved Earth's low-altitude Vulkan terrain streaming so higher-detail meshes become available more steadily at lower frame rates.
- Kept pad deck height from raising nearby terrain, with Titan launchers remaining settled on their pads after a scenario reload.
