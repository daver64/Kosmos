This is the Proton vehicle used to launch Salyut, Mir and ISS modules.

It has a cargo fairing and is three stage with only thurst vectoring
and vernier engines for directional control.

Press "j" to jettison stages prematurely, or jettison payloads described
in the scenario file using the Generic Payload Description System (GPDS).

Press CTRL-* to turn off verniers on the third stage.

You may add HEIGHT n to the scenario file to vary the height standing
on the pad.

Two scenario files are included. One requires the CVEL-fregat from the
CVEL website (below).

http://projectganymede.sourceforge.net/cve-lite


Please see HOWTO-GPDS.txt for information on defining payloads, or the
GPDS page at the CVE-lite homepage, above.
