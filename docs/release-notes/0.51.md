# Kosmos 0.51

## Install and run

- **Windows (64-bit):** Download `kosmos-beta-0.51-Windows.zip` from the assets below, extract it, and run `kosmos-launcher.exe` inside the extracted folder. Use Windows 10 or later with up-to-date graphics drivers; the Vulkan runtime (`vulkan-1.dll`) is required, even when using another graphics backend.
- **Linux (64-bit):** Download `kosmos-beta-0.51-Linux.tar.gz`, extract it, and run `./kosmos-launcher` from the extracted folder. This build requires glibc 2.38 or newer, a graphical desktop and OpenGL 4.3 graphics drivers. On Ubuntu 24.04, install its runtime libraries with:

  ```sh
  sudo apt install libwxgtk3.2-1t64 libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-mixer-2.0-0 libsdl2-ttf-2.0-0 libcurl4t64 libpng16-16t64 libopengl0 libvulkan1 zlib1g
  ```

The game archives include fallback scenery, so **the large Orbiter scenery downloads are optional**. You can try Kosmos immediately and add scenery later using the launcher's Scenery packs page. The SDK downloads are optional too.

**SDK documentation:** The 0.51 SDK archives contain an outdated HELLO version description. For the corrected protocol, use the [current SDK manual](https://salyut.ddns.net/kosmos/sdk.html) or [protocol reference](https://github.com/daver64/Kosmos/blob/main/sdk/docs/PROTOCOL.md).

## Changes

- Optional nonspherical gravity now uses spherical-harmonic fields for Mercury, Venus, Earth, Moon, Mars, Ceres and Vesta, using the same datasets and degree limits as Orbiter's configurations. The simulated bodies' ephemerides and orientations remain approximations, so trajectories need not match Orbiter exactly. Rails, time skips and Keplerian orbit predictions still omit these perturbations.
- Pioneer 10 and Voyager's Jupiter scenarios start with their dishes aimed at Earth. A spacecraft Earth-communications attitude hold tracks Earth during physics flight; it does not simulate a radio link or steer on rails.
- Experimental target autoland can aim at a base's pad from nearby or plan an orbit-to-base plane change and powered descent, with Ares on Mars or the Moon and Shuttle-A on suitable bodies. Orbital success is within 3 km of the base centre, not necessarily on the pad; it requires spherical gravity and weather off on bodies with weather. The approximate forecast checks fuel but cannot guarantee a landing or avoid obstacles. Local approaches descend faster above 1000 m; autoland blocks time skips and aborts if the body or stage changes.
- Orbital base autoland shows the time to plane burn during the wait, recheck and alignment. Planning and checking run at 1x; alignment, burn and descent permit up to 4x physics warp.
- Nuclear explosions, beam weapons and thunder now use synthesised sounds rather than recordings. Sound credits identify the bundled XRSound effects.
- Restored the Deltaglider, Dragonfly and Shuttle-A model assets, and removed scenarios for add-ons not included in this release.
- Restored the converted Orbiter Kennedy LC-39B pad and Vehicle Assembly Building meshes used by the Kennedy base.
- Restored the Delta IV and Titan model assets and textures so their launch vehicles render in packaged builds.
- Restored five CVEL Saturn V variants with Apollo 11 launch-day pad scenarios; MLV3 now uses the existing stretched S-II mesh.
- Fixed the Deltaglider nose-cone surfaces by preserving both texture sides while culling their reverse-wound faces.
- Regenerated launcher preview thumbnails for all shipped scenarios.
- Restored the Soyuz TMA's missing surface textures.
- The Engine MFD now reads live fuel flow directly, including hover-engine use.
- Shuttle-A ascent holds its launch heading until it clears the Helsinki launch tower.
- Added the NASA Space Exploration Vehicle at Tranquility and Curiosity at Gale Crater, with battery-powered rover driving.
- Restored CVEL Salyut and its deployable solar arrays, and repaired Mir lighting and Deltaglider cockpit artwork.
- Improved launcher scenario previews and scenery download progress and queue controls.
- Escape closes the active panel or window; Control+Escape quits the simulator. Habitat entrance labels can be toggled in settings.
- Game updates and optional standard Orbiter scenery are hosted on GitHub; the Kosmos website continues to host the manuals and log reports.
