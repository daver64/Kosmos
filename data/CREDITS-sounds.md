# Sound credits

The effects in `data/sounds/` come from the XRSound add-on for Orbiter, copyright (c) 2018-2021 Douglas E. Beachy,
released under the MIT licence (see `sounds/LICENSE-XRSound.txt`). https://www.alteaaerospace.com

| File | Used for |
|------|----------|
| `main_engines.wav` | Main engine loop |
| `rcs_sustain.wav` | RCS thruster loop |
| `touchdown.wav`, `crash.wav` | Landing and impact |
| `docking.wav`, `undocking.wav` | Docking and undocking |
| `thump.wav` | Stage separation |
| `warning_beep.wav` | Systems alarm |
| `gear_up.wav`, `gear_down.wav` | Landing gear |
| `nuke.mp3` | Atom bomb blast (supplied by the project owner; source and licence to be recorded) |

Other files in the folder are available to add-ons and Lua scripts. If a file is missing, Kosmos falls back to its
synthesised engine sounds or stays silent for that event.
