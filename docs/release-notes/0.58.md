# Kosmos 0.58

## Changes

- Added CVELN1, an N1-inspired three-stage cargo launcher with original meshes, split shroud, a Baikonur scenario and an ascent autopilot. The shroud and unseen details are approximate; the autopilot was tested with a 95-tonne payload to a 200 km Earth orbit.
- Added a session-only Performance metrics window with frame, CPU, GPU, memory and terrain diagnostics; availability varies by backend.
- The Buran-on-Energia scenario now carries Centaur G, Fregat and Luna E3 in the payload bay. The Energia propellant loads are increased for this payload and are not historical.
- Adjusted Deltaglider lift, elevator response and exhaust placement, and updated exterior materials for the Deltaglider, Ares and Energia-M.
- Compressed scenario thumbnails losslessly, removed superseded preview files and made new in-game thumbnail captures compressed.
- Replaced the CVEL Fregat's visual model with a new textured, approximate model.
- Reduced repeated switching between terrain renderers during low, slow flight when experimental ground relief falls back.
- Prevented floating rocks and other solid clutter when experimental ground relief differs from collision terrain.
- Fixed blurry Vulkan relief imagery caused by exhausted texture descriptors.
- Blended the Gale Crater terrain mesh more gradually into the surrounding Mars surface.
