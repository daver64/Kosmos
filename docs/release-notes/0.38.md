# Kosmos 0.38

- KosmosCAD: textured view. Z now cycles the active view through wireframe, solid and textured; textured shows each material's image (PNG, JPG or Orbiter DDS), with plain colour for materials that have none (or a checker, from the UV editor panel). View > Render image (PNG)... saves the textured perspective view without the grid and gizmos.
- KosmosCAD: a Blender-style UV editor (U). The left half shows the material's image with the UV wireframe of the selected faces (or objects) over it; drag to move, rotate (R) or scale (S) the mapping, click or Ctrl+drag to pick UV points, flip, rotate 90, fit to 0..1, or type exact numbers. The part updates live in the textured perspective view, and each drag is one undo step.
- KosmosCAD: the views now fill the whole window. The scene list and the properties are floating tool windows (Scene F2, Properties F3, or the toolbar and View menu) that you can drag anywhere.
- KosmosCAD: the views are anti-aliased (4x multisampling) and the perspective depth range is tighter, which removes the speckle and z-fighting on dense meshes.
- KosmosCAD: a Modify menu holds the modelling tools (extrude, inset, mirror, booleans, sketch and so on), the window layout is remembered between sessions, and the status bar lists the main keys on start.
- KosmosCAD: the UV editor draws the other faces of the object faintly in Face mode, with tick boxes to hide the UV points or the faint faces.
