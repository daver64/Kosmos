# Kosmos 0.55

## Changes

- The launcher's Update now installs the new version over the current folder instead of unpacking a second copy. It refuses while Kosmos is running. Your own addons, scenery and settings are kept, the running launcher is replaced safely, and it offers to restart. Launchers from 0.54 and earlier still unpack beside the old folder, so that first update to 0.55 works the old way.
- Fixed the CVEL Shuttle-A family's 2D cockpit: the main and fuel panel backgrounds were missing, so the instruments floated on nothing. The Nuclear and Q variants use the same panels.
- Terrain relief now renders Earth and the current non-Earth sphere-of-influence body from orbit toward the surface when Orbiter imagery and elevation are available. Ground relief is on by default; new settings also enable Earth's relief-from-orbit option, while saved preferences are preserved. Kosmos falls back to its existing renderer when the required data is unavailable or local terrain checks do not agree.
