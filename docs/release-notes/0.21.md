# Kosmos 0.21

- New: interactive buildings. A building is a fixed, enterable structure that uses the ship format (power, tanks, pressure vessels, 2D panels). Walk up to its door on foot and press Enter to go inside: you get its control panel and the F1 systems window, and you can run base systems such as life support, power, communications and in situ resource extraction. Press Enter again (or View > Leave building) to step back out. The menu item reads "Board ship / enter building" on foot.
- New: the Gale Crater base on Mars has four buildings: a habitat (life support), a power and maintenance plant, a communications mast and a regolith water (ISRU) plant, each with its own working panel. Pumps, compressors and dishes wear out with use until you press Repair all.
- New: scenario 47, "Mars: inside the Gale habitat", starts you inside the habitat; a scenario can set `"enter_building": "<building name>"` for this, and `--enter-building TEXT` does the same from the command line.
- New for modders: addons list buildings in `addon.json` (`"buildings": ["habitat.json"]`); a building file is a ship file with `"class": "building"`, a `door` point and `door_radius`. A base object `{"type": "building", "building": "<name>"}` places one. Buildings are pinned to the ground and ignored by V (cycle ship) and by boarding.
- New for modders: 2D panels without artwork. Panel controls can have a `label` and the types `label`, `readout`, `gauge` and `lamp`, bound to any property; `{ship}` stands for the panel's own ship in a control property.
- New for modders: system components `isru` (water from regolith, `kg_per_day`) and `comms`; any component can set `wear_hours` and fails when worn out until `{ship}/systems/repair` is set to 1. Each component's switch is `{ship}/systems/component[N]/enabled`, with `powered`, `wear` and `failed` beside it.
- Changed: the first-person (EVA) view is less fish-eyed (60 degrees vertical instead of 75).
- Changed: walking around a building on foot no longer hits an invisible wall. A building with a lathe-profile shell, such as the Gale habitat dome, is now solid only where the shell really is at your foot and head height, and the clearance around it is 0.1 m instead of 0.3 m, so you can stand close to the curved wall. Buildings built from a model still use a plain cylinder around each stage.
- Changed: on foot, Space now jumps and Ctrl crouches (they were the other way round); in zero gravity Space moves you up and Ctrl down.
- Changed: boulders on airless rocky worlds take the colour of the terrain around you.
- Changed: a ship standing on the ground keeps its lights off while the Sun is up, and the Ares Spider's lights are dimmer.
- Docs: the flight manual has a Buildings section and an On foot (EVA) entry in its side menu; the modders' manual has a Buildings section, the new panel control types and the new system components.
