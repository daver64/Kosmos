# Kosmos 0.30

0.30 begins stabilisation: a code review and an audit of the manuals against the source.

## Fixes
- A base whose body could not be found no longer reads a pole for body -1 in the base editor.
- The live-weather fetch thread and the main thread no longer share a plain flag, which was a data race.
- Removed unused variables and a doubled assignment that the compiler flagged.
- The Windows launcher failed to start on some machines ("GetWindowSubclass could not be located"); it now carries the Common Controls 6 manifest.
- The CVEL Transtage exhaust plume was about four times too long; it now matches the Centaur G.

## Content
- New scenario `20_transtage_orbit`: the Transtage and its probe in a 400 km orbit.

## Internals
- No behaviour change: function-local statics now live in the app state or in file scope, and the link server message handler, the ship loader, the per-frame time step, camera placement, input handling, world setup, startup tool modes, HUD and scene drawing, terrain creation, the menus, settings, part and camera windows, universe and generated-system loading, weapons and weather updates, interiors, terrain meshes and the base and scenario editors are split into smaller functions. Several `std::function` members of the app are now ordinary member functions.
- Earth and the Moon are no longer special-cased by name. Earth's `real_world` and `imagery` flags, the Moon's `fallback_texture`, per-body land cover and weather station files (`data/landclass/<system>/<body>`, `data/weather/<body>_stations.json`) and the measured climates in `data/weather/bodies.json` are now data. Behaviour is unchanged.

## Documentation
- Flight Manual: the hover and pod keys, and the video, test and window command-line options that were missing.
- Modders Manual: `camera_target`, `horizontal`, `hybrid`, `module`, `isp_sl` and the engine plume keys (`plume` is the flame length in metres); scenario `enter_building` and `orbit.escape_to`/`escape_days`; body `pole`, `meridian`, `epoch_rates`, `detail*`, `minor` and belt radii.
- SDK: `kl_parse_step` is documented and the header comment names protocol version 3.
