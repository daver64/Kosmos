# Kosmos 0.41

- Every base building (habitats, power plants, comms masts, ISRU plants at Tranquility, Mare Frigoris, Caloris and Gale) now has a walkable interior with an airlock hatch and its control panel inside; before, only the Mare Frigoris quarters did.
- On foot, the Geology Sample readout, the pack list and the full Suit Life Support panel no longer sit on the screen. They are pages on the tricorder (environment, suit, samples, pack); click with it held to flip pages. The suit panel pops up on the HUD only when oxygen, power or pressure get low, and a compact status line shows heading, altitude and speed.
- The Deltagliders no longer carry the ICBM targeting MFD. OrbitComp's Plan page now plans a return from a moon to its planet (for example Moon to Earth: departure dV, flight time, arrival periapsis and when to burn), and the Transfer MFD points to it when the target is not in your orbit's frame.
- The Atlas III (scenario 02) now has a two-piece payload fairing that jettisons with the booster, and carries a Luna E3 probe on its Centaur; stage again to release the probe. The probe's engine plume is much smaller, so it no longer swamps the model.
- The launcher shows scenario subfolders as a nested tree (for example CVEL > CVEL-Atlas), and finds a scenario's thumbnail in any thumbs/ folder above it.
- Scenario files no longer start with a number (`dragonfly_orbit.json`, not `07_dragonfly_orbit.json`), so they can be moved between folders freely. A scenario's id is still its file name, so `--scenario dragonfly_orbit` is the new form; a launcher "last scenario" saved under an old numbered id is simply not found until you pick again.
