# Kosmos 0.44

- The ICBM Targeting MFD calculates range to target directly from active vehicle telemetry and coordinates, updates in real time, and shows in-flight range and time to detonation counting down.
- File ▸ Set time to T-5:00 before burn skips the clock to just before the burn the Transfer or OrbitComp MFD shows (or a Hohmann estimate to the target when neither does). File ▸ Transfer windows lists the next departure windows to the target, each with a Go to button. The lead time is adjustable. Not available in multiplayer, or while landed, in the air or burning.
- Scenarios can set `mfd_power` (each MFD on or off), `mfd_display` (panels, see-through or off) `hud` (the HUD mode) and `view` (chase, cockpit or cockpit3d), besides `mfd_left` / `mfd_right`. The default Kestrel start now has the Orbit MFD on the left and the right MFD off.
- OrbitComp PLN has AUTO and ABORT buttons: AUTO arms the burn autopilot from the plan on screen (ejection, Hohmann or return), holding prograde, igniting at the right time and cutting off at the planned speed. The Transfer MFD's AUTO is unchanged.
- OrbitComp keeps showing an ejection once the burn has taken you out of a bound orbit: target v-infinity, current v-infinity, dV left and burn time left, instead of "Needs a bound orbit".
- File ▸ Set time to T-5:00 before burn now reaches the burn for a long ejection wait (it gave up part way when re-planning moved the burn later).
- The Orbit MFD on an escape trajectory rescales to keep the ship on the display (it used to run off the edge once far from the planet) and shows ESCAPING with the excess speed.
- Shuttle-A: both main engines sat on the left side, so a burn yawed the ship and only the left Main gauge moved. The right engine is back on the right.
- Time warp is no longer held at 100x just after an escape burn from low orbit: an outbound unbound ship is not treated as heading for the atmosphere.
- Time warp above 100x is allowed whenever the ship's orbit stays clear of the atmosphere, not only on an escape path.
- Deltaglider (Nuclear): the Nose docking port is now the first (default) port; the belly Cradle is second. The Dragonfly scenario now docks the Deltaglider by its nose, and the Energia-M scenario uses the Cradle.
- OrbitComp PLN transfer diagram: the ship dot now travels along its own orbit (it used to be pinned at one spot while only the target moved, which looked frozen at high time warp).
