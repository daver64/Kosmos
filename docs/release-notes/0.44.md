# Kosmos 0.44

- The ICBM Targeting MFD calculates range to target directly from active vehicle telemetry and coordinates, updates in real time, and shows in-flight range and time to detonation counting down.
- File ▸ Set time to T-5:00 before burn skips the clock to just before the burn the Transfer or OrbitComp MFD shows (or a Hohmann estimate to the target when neither does). File ▸ Transfer windows lists the next departure windows to the target, each with a Go to button. The lead time is adjustable. Not available in multiplayer, or while landed, in the air or burning.
