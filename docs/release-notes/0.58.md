# Kosmos 0.58

## Changes

- Added CVELN1, an N1-inspired three-stage cargo launcher with original meshes, split shroud, a Baikonur scenario and an ascent autopilot. The shroud and unseen details are approximate; the autopilot was tested with a 95-tonne payload to a 200 km Earth orbit.
- Compressed scenario thumbnails losslessly, removed superseded preview files and made new in-game thumbnail captures compressed.
- Replaced the CVEL Fregat's visual model with a new textured, approximate model.
- Prevented floating rocks and other solid clutter when experimental ground relief differs from collision terrain.
