Nov 2004: Converted to CVE-Lite.

Notes:  Works as a launcher OR as an upper stage (with Energia, not included).
It should be possible to set both configuration and booster choice by stating the vessel type, i.e.:
	EnergiaM 	: The Energia-M with its own "slick" LRB's
	EnergiaMp	: p is for Parachute; the 'chute-pack-equipped LRB's of the big Energia
	EnergiaMCore	: Core only.  Skip the boosters

Unhappily, this part still doesn't work right.  Instead, set BOOSTERCHOICE 0, or to 1 for EnergiaP.  Set CONFIGURATION to 1 for core only.  This works, but will need further attention.
